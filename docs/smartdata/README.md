# Cloudberry 3.0 — тексты к докладу

Развёрнутые описания четырёх фич. Каждый текст соответствует одной карточке
презентации.

| № | Текст | Карточка | О чём |
|---|---|---|---|
| 01 | [Ядро PostgreSQL 16](01-postgres16-merge-into.md) | `01-postgres16-merge-into.pdf` | Обновление ядра с 9.4 до 16 на примере `MERGE` |
| 02 | [YAGPCC 2.0](02-yagpcc-2.0.md) | `02-yagpcc-2.0.pdf` | Дашборды кластера и live-план выполнения запроса |

Сквозная линия: обновлённое ядро PostgreSQL 16 — это не только новый синтаксис,
но и фундамент, на котором строятся остальные три фичи. Parallel join приходит
прямо из PG16, Anser и YAGPCC используют его инфраструктуру исполнителя.
